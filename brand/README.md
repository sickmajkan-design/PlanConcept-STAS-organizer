# QPlan brand files

Vector sources (SVG, edit freely, no fonts needed):

| File | Use |
|---|---|
| `qplan-mark.svg` | the mark on a light background |
| `qplan-mark-dark.svg` | the mark on a dark background |
| `qplan-mark-white.svg` | white, on orange or a photo |
| `qplan-mark-mono.svg` | one colour (ink), for print and stamps |
| `qplan-logo.svg` and `-dark`, `-white`, `-mono` | mark + the word "Plan", drawn as vector |
| `qplan-icon.svg` | app icon, 1024 px, orange tile |
| `qplan-favicon.svg` | simplified for 16 and 32 px |

The PNG icons of the panel (`src/construction_admin/public/icons`), Android (`mipmap-*`, `drawable-*/ic_launcher_foreground.png`, `ic_splash.png`) and iOS (`AppIcon.appiconset`) are exported from these. Rules for use: `docs/BRAND_PLAN.md`.
